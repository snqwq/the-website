# the-website

## goals
- **no AI**
- make something I'm actually proud of
- have it be visited by people I don't know

## about
I have been in a bit of a lull programming wise for a while now, and I've found myself being less motivated and less proud of my projects. I've essentially stopped doing much past simple Python scripts. I've also noticed myself using more AI in my development, whether that's for planning, thinking of a stack, or using it instead of reading docs. I find that my usage of AI has, to put it bluntly, made me a worse programmer. So recently, after seeing some videos and stuff on indieweb and personal web and stuff (I don't really know much about the differences of these tbh), I've decided to try and get some of my skills back and to actually make something I'm proud of by making a personal website for me and by me. So I hope whoever you are, you enjoy whatever I decide to make :)
